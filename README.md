# 部屋の代替わり・引き継ぎキット

Museとの部屋（サイドチャット）は、会話が長くなるほど、毎回の読み直しにかかる量が増えていきます。対策は「部屋を小さく保つ」ことではなく、頃合いを見て新しい部屋へ代替わりし、文脈は引き継ぎ文書に凝縮して渡すことです。

もう1つの理由は、引き継ぎそのものの質です。引き継ぎは「文書を置いた時」ではなく「相手が始めた時」に終わります。このキットは、その形を定型にした道具一式です。

## 中身

- `SKILL.md` — 代替わりと引き継ぎの進め方（Museへ渡して使います）
- `引き継ぎ文書の型.md` — 引き継ぎ文書に入れる項目の書式
- `新室の憲章の型.md` — 新しい部屋の最初の指示（憲章）の書式

## 最初の一歩

本命は、GitHubから直接取り込む「2段の形」です。最初に1回だけ取り込んでおけば、あとは短い頼み方で動きます。

### 1段目：取り込み（最初に1回だけ）

自分のClaudeに次の文を貼ります。Claudeがこの保管庫を開いて、入っている進め方（SKILL.md）を、自分の側に保存します。

> https://github.com/rascalrascal/muse-token-kits を開いて、中身を読んでください。入っている進め方（SKILL.md）を、今後も使えるように、あなたの側に保存してください。保存できたら、その旨を教えてください

### 2段目：使う時の短い頼み方

取り込みが済んだら、あとは短く頼むだけです。進め方は「最後まで任せる形」です。Claudeが引き継ぎ文書と最初の指示文を作って全文を見せ、ご本人がよいと言ったら、Claudeが新しい部屋を作って引き継ぎを渡し、新しい部屋が作業を始めたことを確認して、古い部屋を閉じます。文書を見せて了承を得る所（確認の門）だけは、必ず残ります。

メインの会話で（どの部屋を代替わりさせるかから相談する形）：

> 太っている部屋はありますか。候補を出してください

候補から選んだら：

> その部屋の代替わりを進めてください。まず引き継ぎ文書と、新しい部屋への最初の指示文をキットの型で作って、全文を私に見せてください。私がよいと言ったら、新しい部屋を作って引き継ぎを渡し、新しい部屋が作業を始めたことを確認して、古い部屋を閉じてください。定期的なお届けがある部屋は、新しい部屋へ付け替えてください

部屋の中で（その部屋を代替わりさせる形）：

> この部屋の代替わりを進めてください。まず引き継ぎ文書と、新しい部屋への最初の指示文をキットの型で作って、全文を私に見せてください。私がよいと言ったら、新しい部屋を作って引き継ぎを渡し、新しい部屋が作業を始めたことを確認して、古い部屋を閉じてください。定期的なお届けがある部屋は、新しい部屋へ付け替えてください

紹介記事にも、同じ趣旨の「貼るだけのプロンプト」が載っています。

ページを開けない環境では、予備として「ファイルを貼る方法」が使えます。ファイル一式を使うと、進め方そのものを手元に置いて、毎回同じ形で回せるようになります。手順は次のとおりです。

## 使い方（ファイルごとの手順）

### 1. `SKILL.md`（進め方の本体）

分担の基本：Claudeが、引き継ぎ文書と最初の指示文を作って見せる所から、新しい部屋を作って引き継ぎを渡し、始めたことを確認して古い部屋を閉じる所までを通して行います。ご本人の手は、文書を見て了承を出す所だけです（了承があるまで、Claudeは新しい部屋を作りません）。

1. ファイルを開き、全文をコピーします
2. 代替わりさせたい「今の部屋」に貼って送ります
3. Claudeが進め方を読み、引き継ぎ文書と最初の指示文を作って、全文を見せます
4. ご本人が文書を見て了承したら、Claudeが新しい部屋を作り、最初の指示文と引き継ぎ文書を渡して、始めたことを確認します

### 2. `引き継ぎ文書の型.md`（書式）

進め方の中で「引き継ぎ文書を作る」段階で使います。

1. ファイルを開き、全文をコピーします
2. 引き継ぎ文書を作っている部屋の会話に貼り、「この書式で引き継ぎ文書を作ってください」と一言添えて送ります

Claudeはこの書式に沿って、決め事・現在地・未完の仕事などを項目ごとに埋めた引き継ぎ文書を作り、全文を見せます。出来上がった文書は、ご本人の了承の後に、Claudeが新しい部屋へ渡します。

### 3. `新室の憲章の型.md`（書式）

進め方の中で「新しい部屋への最初の指示を書く」段階で使います。

1. ファイルを開き、全文をコピーします
2. 憲章を作っている部屋の会話に貼り、「この書式で新しい部屋の憲章を作ってください」と一言添えて送ります

出来上がった憲章（最初の指示文）は、ご本人の了承の後に、Claudeが作った新しい部屋の最初のメッセージとして、Claudeが送って使います。

## 骨格

分担：文書作りから新しい部屋の開始確認まではClaude、本人の手は文書を見て了承を出す所だけです。

1. 発動の目安：1つの部屋の消費の偏りが大きくなった時／読み込み量が目立って上がった時／テーマの区切りがつき、残りが参照用の記録になった時
2. （Claudeの仕事）引き継ぎ文書を作る（決め事・現在地・未完の仕事・呼び方の注意を含む）。旧室の会話全文は写さない
3. （Claudeの仕事）新しい部屋への最初の指示文（憲章）を作る。短く、目的＋引き継ぎ文書を読む指示＋最初の仕事だけ
4. （確認の門）両方の全文を本人に見せ、了承を得る。了承があるまで、新しい部屋は作らない
5. （Claudeの仕事）新しい部屋を作り、最初の指示文を送り、引き継ぎ文書を渡す
6. （Claudeの仕事）新しい部屋が引き継ぎを読んで作業を始めたことを確認する。**引き継ぎは、相手が「始めた」と報告するまで完了にしない**
7. （Claudeの仕事）旧室を閉じる（履歴として残す形にする）。削除は本人の明示の言葉がある時だけ
8. 旧室に付いていた定期実行の届け先は、新室へ付け替える
